## Welcome to KeePass Web

**A password manager with no backend, just self-contained HTML files that read
and write your KeePass database, wherever it lives.**

Do you find yourself:
* Wanting complete control over where your passwords are stored?
* Unable or unwilling to install a native application?
* Distrusting software that handles your passwords?

Then KeePass Web may be for you!

With KeePass Web, you're in control of...
1. Where your database lives: a USB stick, your computers's hard drive, or
   in your cloud storage account.
2. Where the app's code comes from: download it once and run it offline
   forever, or open the provably identical pages at [keepass-web.app](https://keepass-web.app)
   without ever installing anything.
4. What the computer allows: even on a kiosk or library terminal where
   you can't install anything or save a file, [keepass-web.app](https://keepass-web.app)
   plus your own cloud storage means nothing ever touches that computer's
   disk and nothing is left behind when you walk away.

Mix and match to suit your situation: run a downloaded copy against a cloud
database, or the hosted copy against a local file.
