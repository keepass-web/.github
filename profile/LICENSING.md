# Licensing, and the KeePass Web Business Model

KeePass Web is free to use. If it saves you trouble,
[tell someone who'd like it][share], [star the source repository][repo], or
[become a sponsor][ghs].

We believe that password and secret management software is too important to
wall behind a proprietary corporate shield: allegiance to shareholders shifts
focus from security to profit. So we keep everything open and free to
everyone.

## Open and Free

All of KeePass Web is open source under the [MIT license][mit], always: a
multi-page application of self-contained HTML pages that read and write KDBX
databases in your browser. It is never paywalled, never time-delayed, and
always current. Security fixes ship to everyone immediately.

The local version is one you open from your own disk; the online version at
[keepass-web.app][kpo] is not hosted by us — GitHub Pages serves the exact
same files, verbatim from a public repository, and there are no KeePass Web
servers.
